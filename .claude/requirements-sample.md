## FR 샘플

### FR-SHELL-01 — 상단바 탭으로 페이지 이동

| 속성 | 값 |
|------|-----|
| **우선순위** | MUST |
| **상태** | ✅ 구현됨 |
| **구현 위치** | `/whale-app/src/App.tsx` · `/whale-app/src/components/TopBar.tsx` |

#### 행위

**조건**: 사용자가 앱이 로드된 화면에서 상단바를 본다.

**액션**: 사용자가 상단바 가운데 nav의 [Home] / [E2E] / [Library] 탭 중 하나를 클릭한다.

**결과**:
1. 화면 본문이 클릭한 페이지로 즉시 전환된다.
2. 클릭한 탭이 흰색 배경과 그림자로 활성 표시되고, 나머지 탭은 흐린 텍스트로 비활성 표시된다.
3. 상단바 우측 영역에 페이지별 위치 정보(breadcrumb)가 표시된다.
   - Home: breadcrumb 표시 없음
   - E2E: `sensor-A / night-tuning / pass-3 · rev-7`
   - Library: `library / all images`
4. 사용자가 다시 앱을 열었을 때(새로고침 / 재진입) 마지막으로 머물던 페이지가 다시 열린다.

#### 측정 기준

- [ ] 탭 클릭 후 본문이 1초 이내에 전환된다.
- [ ] 어느 시점에서도 활성 표시된 탭이 정확히 1개이다.
- [ ] 새로고침 후 마지막에 보던 페이지가 그대로 표시된다.
- [ ] breadcrumb가 페이지 전환과 동시에 갱신된다 (지연 없음).

#### 평가 기준 없음

- 페이지 전환 시 시각적 트랜지션(페이드 등)이 필요한지에 대한 디자인 기준 없음. 현재는 즉시 교체.

## NFR 샘플

### NFR-THEME-01 — 액센트 색상 변경 시 즉시 반영

| 속성 | 값 |
|------|-----|
| **카테고리** | 디자인 시스템 / 테마 |
| **우선순위** | MUST |
| **상태** | ✅ 구현됨 |
| **구현 위치** | `/whale-app/src/App.tsx` · `/whale-app/src/styles/tokens.css` |

#### 행위

**조건**: 사용자가 Tweaks 패널이 열린 상태에서 임의의 페이지를 보고 있다.

**액션**: 사용자가 Tweaks 패널의 Accent color 스와치 4종(`Ocean` / `Teal` / `Amber` / `Graphite`) 중 하나를 클릭한다.

**결과**:
1. 화면의 모든 강조 색상이 새 액센트로 즉시 변경된다.
   - 활성 탭, primary 버튼 배경, 활성 사이드바 항목, 활성 배지, 슬라이더 진행 영역, 선택된 노드/카드의 보더, 카테고리 점 등.
2. 선택된 스와치는 검은 외곽선으로 활성 표시된다.
3. 다른 페이지로 이동해도 변경된 액센트가 그대로 유지된다.

#### 측정 기준

- [ ] 스와치 클릭 후 색상 변경 시 화면 깜빡임이나 흰색 플래시가 발생하지 않는다.
- [ ] 4종 액센트 모두 액센트 위에 올라가는 흰색 텍스트와 명도 대비 4.5 : 1 이상을 만족한다 (WCAG AA 본문 기준).
- [ ] 페이지 이동 시 액센트가 초기화되지 않는다.

#### 평가 기준 없음

- 호버 색(`--accent-hover`)이 본 색과 시각적으로 충분히 구분되는지에 대한 명시 기준 없음. 디자이너 검토에 의존.
- 액센트 4종 간 시각적 차이가 충분한지에 대한 명시 기준 없음.
